How the score works

Collect

We read the latest 100 commits, 20 pull requests and every review on them, straight from the GitHub API.

Weigh

Each action earns points. Bigger contributions earn more.

  • Commit 1
  • Pull request opened 2
  • Pull request merged 3
  • Review given 2

Judge

A Gini coefficient turns the split into a 0 to 100 score. 100 means everyone did equal work. Anyone above 1.5 times or below half of a fair share is flagged.

Reviewing your own pull request earns nothing, and trivial commits are skipped, so padding the history does not help.
